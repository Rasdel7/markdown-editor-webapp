# Live Markdown Editor ✍️

Write markdown with live preview, templates
and export to .md, .txt and .html formats.

## Live Demo
[Click here](https://markdown-editor-webapp-f8z8qnha8hvskcsnidfnr9.streamlit.app)

## Features
- Split editor and live preview
- 6 professional templates
- Toolbar buttons for quick formatting
- Word, character and line counter
- Save and load multiple documents
- Export as .md, .txt or .html
- Markdown quick reference sidebar

## Templates Included
- GitHub README
- Blog Post
- Project Documentation
- Meeting Notes
- Data Science Report

## Tools Used
- Python, Streamlit, Markdown

## How to Run Locally
pip install streamlit markdown
streamlit run app.py
